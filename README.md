# Dotfiles

## Overview
This repository contains my personal dotfiles and configurations for various tools and applications that I use on a daily basis. These configurations are tailored to my workflow and preferences, and they help me maintain a consistent and efficient working environment across different machines. These dotfiles include settings for my terminal, shell, editor, and other utilities that enhance my productivity and overall user experience. The following is a list of the key components and tools that are configured in this repository:

- Font Family: `Maple Mono Normal Nerd Font`, `Hack Nerd Font Mono`, ...
- Shell: `fish`, `zsh`, `bash`
- Terminal: `ghostty`, `alacritty`, `kitty`, `wezterm`
- Editor: `nvim`
- File Manager: `yazi`
- Resource Monitor: `btop`
- Git Client: `lazygit`
- System Information: `fastfetch`
